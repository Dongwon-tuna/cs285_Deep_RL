# CS285 Fall 2023 – Reinforcement Learning Implementations  

This repository contains my implementations of algorithms from **CS285 (Deep Reinforcement Learning, UC Berkeley) Fall 2023**.  
Across HW1–HW5, I implemented a wide range of classic and modern reinforcement learning algorithms, spanning **behavioral cloning, policy gradients, Q-learning, model-based RL, and offline RL**.  

---

## 📘 Implemented Algorithms  

### HW1 – Imitation Learning  
- **Behavior Cloning (BC)**  
- **DAgger (Dataset Aggregation)**  

### HW2 – Policy Gradient  
- **Policy Gradient (with value function baseline)**  
- **Generalized Advantage Estimation (GAE)**  

### HW3 – Value-Based RL  
- **Q-Learning**  
- **Double Q-Learning**  
- **Soft Actor-Critic (SAC)**  
- **Clipped Double Q-Learning**  


### HW4 – Model-Based RL  
- **Model Predictive Control (MPC)**  
- **Cross-Entropy Method (CEM)**  
- **Model-Based Policy Optimization (MBPO)**  

### HW5 – Offline RL  
- **Random Network Distillation (RND)**  
- **Conservative Q-Learning (CQL)**  
- **Advantage Weighted Actor-Critic (AWAC)**  
- **Implicit Q-Learning (IQL)**
